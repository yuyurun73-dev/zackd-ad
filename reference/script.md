# 台本の型（約1分〜75秒）

説明動画ではなく広告なので、短尺VSLの骨格に乗せる。尺の3割強をクローズに使う。

| 段 | 行数 | 中身 |
|---|---|---|
| フック | 1〜2 | 対象の名指し＋言い切り。「◯◯で焦っているママへ」「遅れているのは子どもでも育て方でもありません」 |
| 感情の場面 | 4〜5 | 買う人が毎日見ている場面を、生の声の言葉で。1行1場面。説教しない |
| 原因 | 1〜2 | なぜ起きるのか。なぜ今までの手が効かなかったのか。**免責で締める**（あなたのせいではない） |
| ほかの手を潰す | 1 | 代わりの方法だと別の困りごとが起きる |
| 放置した先 | 1 | このままだとこうなるかもしれない、を1枚の絵で |
| 解決と商品 | 2〜3 | 必要なのは何か → 商品名 → 仕組みを1〜2行 |
| 先の姿 | 1 | 使った後の一場面 |
| クローズ | 4〜5 | 使い方 → 保証 → 在庫 → 二択 → 商品名つきのCTA |

## 感情を主役にする

買う人と使う人が違う商品（子ども用品など）は、仕組みの説明を主役にすると買う人が自分ごとにならない。
買う人の感情（焦り・苛立ち・後悔・まわりとの比較）を先に並べ、仕組みは「だからあなたのせいではない」の理由に下げる。

- まわりとの比較：「公園で同い年の子が…」「ママ友から…と連絡が来る」「帰り道ずっと『なんでうちだけ』と考えてしまう」
- 苛立ちと後悔：「気づいたら鬼の形相で怒っている」「寝顔を見ながら後悔する」
- 共感されるのは「許し」。責める口調は反発される。

## 絵にしやすい言い方

1行ごとに「何が映るか」を決めてから書く。映らない行は削る。

| 言いたいこと | モノにする |
|---|---|
| まわりは先に進んでいる | 金色の玉座へ駆け上がる子たちと、取り残された親子 |
| 連絡が来てつらい | 巨大なスマホから紙ふぶきと吹き出し |
| 増えていく | 掲示板の丸が1つずつ点いて、最後の1つだけ灰色 |
| 頭から離れない | 石の吹き出しが頭上にのしかかる |
| 原因はこれ | 台座に載った展示品と金色の「？」 |
| 中で起きていること | 案内役が小さくなって断面の中に立つ |
| みんなが選んでいる | 金色の布をかけた台座を囲む人たち → 布が取れて商品 |
| 期限つきの保証 | 日めくりが数え上がって止まり、ハンコが落ちる |
| 残りわずか | ほぼ空の棚に最後の1つ |
| 二択 | 分かれ道（灰色の道と金色の道） |

## 書き方

- つなぎの読点を打たない（が・て・で・ので・から の後）。短い文はつなげて句点も減らす。
- かぎ括弧は台本では外す（読み上げで間になる）。テロップでだけ `display` で戻す。
- 数字は漢数字（三十日）。金額は入れない。
- 約束は商品ページに書いてある範囲まで。
- 一人称の告白調にしない。ナレーターが場面を描く。
