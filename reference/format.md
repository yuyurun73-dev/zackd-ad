# Zack D. Films型：測った中身

## 本家（YouTube Shorts 6本・再生400万〜1,400万・2026-10-04実測）

| 項目 | 値 |
|---|---|
| 尺 | 26〜36秒（1本だけ15秒） |
| ナレ | 毎秒約3語・全体で6〜8文・ナレーターのみ（画面の人物はしゃべらない） |
| 出だし | 前置きなし。1文目から動作の途中（「セキュリティタグを手で引っ張ると…」） |
| 画 | 1文＝1つの画。文の名詞がそのまま映る |
| カット | ハードカットは30秒で0〜数回。カメラが物の中へ潜って断面を見せ、また外へ引く |
| 記号 | 矢印・✓・✕・発光で「ここ」を指す |
| たとえ | RAMを台所のカウンターに置き換えてから本物に戻す |
| 背景 | 説明パートは青の無地／グリッド。場面パートだけ実景 |
| テロップ | 白の太字に黒フチ・2〜3語ずつ・中央やや下・装飾なし |
| 締め | 皮肉かオチ。最初の画に戻ってループする回もある |

本家はAIではなく、Blender中心の3DCGをチームで制作している。

## 本家58本の実測（再生上位30本＋最新30本・2026-10-10）

一覧に出た400本の再生数の中央値は860万、最大4,700万。

| 項目 | 値 |
|---|---|
| 尺 | 中央値37秒（24〜62秒）。25〜35秒は58本中22本 |
| はっきりしたカット | 中央値0回。58本中41本は1回もない。最大でも4回 |
| ゆるい切り替え | 中央値5回＝約7.5秒に1回 |
| つなぎにかかる時間 | 4〜5コマ（0.15〜0.25秒） |
| 青い背景 | 画面の大半が青になるコマは中央値13%。冒頭が青背景なのは15本だけ |

絵と編集で分かったこと
- **Pixar調ではない。** 人物は実写寄りの3D（少し不気味なくらい）、物の質感は写実。場面は実景か、物と地面の一部だけを置いて後ろを水色のグラデーションにしたもの。
- **グリッドの床は本家には無い。** 青いグリッドのステージは、この型をまねた広告側の約束事。
- **カメラが主役。** 極端な接写、地面すれすれの低い位置、物の中への突入、断面。1文の中でもカメラ位置が何度も変わる。
- **つなぎは4種類**：①飛んでいく物をカメラが追って次の場面に入る ②扉が開くように画面が横へ回り込む ③接写からぶれながら一気に引く ④ぶれの中へ突っ込んで次の接写に抜ける。
- **テロップ**は小さめの白い太字に細い黒フチ、2〜3語ずつ、画面の下から2割あたり。色替えも装飾もない。
- **図解は最小限**：軌道を示す点線、値札、赤い✕くらい。
- **笑いは絵の側**：ありえない物をまじめに写す。ナレは淡々としている。

広告に持ち込むとき：ステージとキャラは広告側の約束事（青いグリッド・Pixar寄り）のままでよいが、
つなぎを4〜5コマで終わらせること、接写と低い位置の構図を混ぜること、1場面を2〜3秒にすることは本家に合わせる。

## この型で回っている広告3本（X @qwertyu_alex 2026-08-25 の投稿・Starpopの記事と同じ3本）

| 広告 | 尺 | 台本の型 | 絵の特徴 |
|---|---|---|---|
| VIASOX（着圧ソックス） | 57秒 | 症状を言い当てる → 仕組み → 同じ言葉を裏返して解決（「血が滞る」→「血が動く」） | 血管の断面・弁が開いたまま |
| Purrick（猫の歯みがき） | 53秒 | 語り手の権威 → 数字の差（25歳と12歳）→「◯◯でも◯◯でもない」→ ルールは一つ → 原因の連鎖 → 商品 → 保証 | 案内役のおじさんが全場面に立つ・金色の巨大な数字・口の中の歯石 |
| BioRoot（ウコン） | 98秒 | 思いこみを崩す → 問題①に成分① → 問題②に成分② → 問題③に成分③ → 並べて比べる | 赤いカップを持った男が機械の中を歩く |

共通点
- **案内役が全編に出る。** 物だけの場面にしない。
- **主張を全部モノにする。** 数字は金色の立体、原因は機械や断面。
- **濃い青のグリッドのステージ**に戻り続ける（離れるのは5秒まで）。
- **3本ともクローズが弱い**（証拠なし・オファーなし・CTA1回）。ここは真似しない。
- 生成の崩れは決め所に集中する：パッケージの文字化け、「95%」のグリッドの数が合わない、商品の形が変わる、
  主人公の顔が別人になる。→ 文字と数は編集で入れる／商品は実物写真を参照に固定／キャラの参照は1枚に固定。

## 作り方の柱（Starpop「Zack D. Films Ad Format」3記事）

1. **声**：落ち着いた淡々とした語り。広告読みにしない。先に全部録って時刻を測る。
2. **ステージ**：1枚のステージ画像を全フレームの参照に付ける。プロンプトで説明するより効く。
3. **キャラ**：1人を1回で固定する。生成結果を次の参照に回さない。
4. **主張＝モノ**：すべての主張を物理的な物にする。
5. **つなぎ**：カットではなく、設計されたつなぎで1本のカメラの旅にする。数秒おきにカットすると偽物に見える。
6. **音**：こもったベースのアルペジオと刻み。仕上げで小さく敷く。生成には入れない。
7. フックは3案出して、絵にしてから選ぶ。フックには商品を出さない。
